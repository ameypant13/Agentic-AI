# Weekly digest

**Route:** `/digest` · **Admins only**

"The last 7 days across the fleet, from the console's own data: findings, certificates, cost, investigations and what
waits for review. No AI."

Non-admins see "Admins only: The digest names every investigation, so only console admins can see it."

What goes into the digest and when it is posted is in [Weekly digest](../concepts/digest.md).

## Reading the page

- **Schedule** (for example "Monday at 04:00 UTC"), when it was last sent, and the 7 days it covers.
- The **headline** and the sections (Findings, Certificates, Cost, Investigations and learning), each with an **open**
  link to the page it summarises.
- **What Slack receives**: the exact Slack text.

## Send it now

1. Click **Send to Slack now**.
2. The status card says "Posted to Slack." or why it was not sent (for example when Slack is muted on this
   environment).

Sending now also counts as this week's send: the scheduled post is skipped if it falls within 24 hours.
